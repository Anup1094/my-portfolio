# Anup Chaurasia — Portfolio

A modern, responsive developer portfolio built with React, Tailwind CSS, and Framer Motion.

## Live Demo
[View Portfolio](https://my-portfolio-anup.vercel.app)

## Built With
- React 19
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Sections
- Hero
- About
- Skills
- Projects
- Experience & Education
- Contact

## Run Locally

git clone https://github.com/Anup1094/my-portfolio.git
cd my-portfolio
npm install
npm run dev
